# memyma

빚이 줄어드는 과정과 부수입이 쌓이는 걸 한눈에 보는 웹앱.

## 기능
- **요약**: 남은 빚, 누적 상환액, 이번 달/누적 부수입, 상환 진행률, 완납 예상 시점(최근 3개월 평균 기준)
- **그래프**: 남은 빚 추이, 최근 12개월 월별 부수입
- **빚**: 여러 개의 빚 등록, 상환 기록 추가/삭제, 빚별 진행률
- **부수입**: 출처·금액·날짜 기록, 출처별 합계
- **백업**: JSON 파일로 내보내기/불러오기

## 사용법
빌드 과정 없음. `index.html`을 브라우저로 열면 바로 동작합니다.
데이터는 브라우저 `localStorage`에만 저장되니 주기적으로 백업 파일을 내려받아 두세요.

GitHub Pages로 배포하려면 저장소 Settings → Pages에서 브랜치를 선택하면 됩니다.
