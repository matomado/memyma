# memyma

빚이 줄어드는 과정과 부수입이 쌓이는 걸 한눈에 보는 웹앱.

## 기능
- **요약**: 남은 빚, 누적 상환액, 이번 달/누적 부수입, 상환 진행률
- **완납 예상 (이자 포함)**: 빚마다 연이율과 월 상환액으로 완납 월과 앞으로 낼 이자를 계산
  - 월 상환액은 직접 정한 계획이 있으면 그걸, 없으면 최근 3개월 평균을 사용
  - 이자는 월복리(연이율 ÷ 12)로 계산하는 근사치
  - 이자보다 적게 갚고 있으면 경고 표시
  - 은행 앱의 실제 잔액을 입력해 이자로 생긴 차이를 맞출 수 있음
- **그래프**: 남은 빚 추이, 최근 12개월 월별 부수입
- **빚**: 여러 개의 빚 등록, 상환 기록 추가/삭제, 빚별 진행률
- **부수입**: 출처·금액·날짜 기록, 출처별 합계
- **백업**: JSON 파일로 내보내기/불러오기

## 사용법
빌드 과정 없음. `index.html`을 브라우저로 열면 바로 동작합니다.
데이터는 브라우저 `localStorage`에만 저장되니 주기적으로 백업 파일을 내려받아 두세요.

## 폰에서 쓰기
1. GitHub Pages로 배포: 저장소 Settings → Pages → Source를 "Deploy from a branch"로, 브랜치를 선택하고 `/ (root)` 저장
   - 무료 플랜에서는 **공개(public) 저장소만** Pages를 쓸 수 있음. 저장소에는 코드만 있고 내 금액 데이터는 브라우저에만 저장되므로 공개해도 데이터는 노출되지 않음
2. 몇 분 뒤 생기는 주소(`https://<아이디>.github.io/memyma/`)를 폰에서 열기
3. 홈 화면에 추가하면 앱처럼 전체 화면으로 열림 (아이폰: 사파리 공유 → 홈 화면에 추가 / 안드로이드: 크롬 메뉴 → 홈 화면에 추가)

PC와 폰의 데이터는 따로 저장됨. 옮기려면 백업 탭에서 파일을 내려받아 다른 기기에서 불러오기.
