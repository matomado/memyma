# memyma — 다이어트 기록 웹앱

운동 · 식단 · 인바디(체중)를 기록하고 주간/월간으로 보는 개인용 웹앱입니다. 빌드 과정 없이 정적 파일만으로 동작하고, 기록은 브라우저(localStorage)에 저장됩니다.

## 기능
- **홈**: 오늘 섭취/소모/순 섭취 kcal, 최근 인바디, 오늘 운동, 이번 주 칼로리 그래프
- **식단**: 아침·점심·저녁·간식. 자주 먹는 음식을 등록해 두면 탭해서 추가하고 kcal는 자동 계산(0.5 단위 수량), 이전 식단 불러오기
- **운동**: 수영(영법·거리), 웨이트(부위·종목·kg/회/세트·볼륨), 유산소(종류·거리), 기타. 소모 kcal는 MET × 최근 체중 × 시간으로 자동 계산(직접 수정 가능)
- **인바디**: 캡처를 올리면 체중·골격근량·체지방량·체지방률·BMI·복부지방률 등을 읽어 입력 → 확인 후 저장. 항목별로 InBody 앱 같은 꺾은선 그래프, 표준 범위 색상, 변화 분석 코멘트
- **기록**: 주간(요일별 리스트 + 막대그래프) / 월간(달력) 보기, 날짜를 누르면 그날 상세
- **설정**: 배경 사진(상단만/전체 배경), 목표 kcal·체중·키·성별, Claude API 키, 백업/복원

## 인바디 캡처 분석
- 설정에 Claude API 키를 넣으면 Claude가 캡처를 읽습니다(정확함, '변화' 그래프 캡처의 여러 날짜도 한 번에 가져옴).
- 키가 없으면 브라우저 안에서 무료 OCR(Tesseract.js)로 읽습니다. 정확도가 낮으니 저장 전에 값을 확인하세요.

## 실행
```bash
python3 -m http.server 8000   # 이후 http://localhost:8000
```
휴대폰에서 쓰려면 GitHub Pages(Settings → Pages → 이 브랜치/루트)로 배포한 뒤 Safari에서 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다.
