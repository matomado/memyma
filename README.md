# memyma

업무용 투두리스트 / 워크리스트 웹앱. 빌드 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 기능
- 할 일 추가: 우선순위(높음/보통/낮음), 마감일, 프로젝트/태그
- 상태 3단계: 대기 → 진행 중 → 완료 (상태 버튼 클릭)
- 보기: 전체 / 오늘·지연 / 진행 중 / 대기 / 완료
- 검색, 태그 필터, 정렬(기본·마감일·우선순위·최근 추가)
- 제목 더블클릭으로 수정, 항목별 메모
- 오늘 완료 수·진행률 표시
- JSON 내보내기/가져오기 (백업·기기 간 이동)
- 데이터는 브라우저 localStorage에 저장
- 단축키: `n` 새 할 일, `/` 검색

## 실행
```
open index.html          # 또는 아무 정적 서버
python3 -m http.server   # http://localhost:8000
```
